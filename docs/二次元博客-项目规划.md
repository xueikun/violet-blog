# 二次元风格个人博客 · 项目规划

> v1.0 · 2026-09-26 · 状态:待确认

---

## 一、项目定位

**一句话**:一个看起来像"视觉小说 / 轻小说站点"的个人博客。

三条铁律:

1. **内容优先** —— 二次元是皮肤,不是本体。任何装饰不得牺牲正文可读性(行宽 ≤ 40 字、行高 ≥ 1.8)。
2. **动效克制** —— 每屏可见区域最多 2 处主动效。目标是"精致",不是"炫技卡顿"。
3. **可维护** —— 发一篇新文章 = 新建一个 `.md` 文件 + 提交。不碰代码。

**访客画像**:自己(长期记录技术笔记 / 生活随笔 / 追番游戏感想)、朋友与同好、未来的面试官。

---

## 二、技术选型

| 方案 | 技术栈 | 优势 | 代价 | 适合 |
|---|---|---|---|---|
| **A(推荐)** | Astro + React 岛屿 + Markdown | 静态输出、SEO 极佳、首屏秒开、视觉自由度最高、md 即文章 | 需基础前端知识 | 内容型博客,首要目标是"好看" |
| B | Next.js (App Router) + MDX | 生态大、能顺手加 API / SSR | 比 Astro 重,配置繁琐 | 未来想加后端逻辑 |
| C | Spring Boot + Thymeleaf + MySQL | 全栈练 Java、可写管理后台 | 二次元动效实现痛苦、开发慢、SEO 弱 | 想顺便练 Java 后端 |
| D | Hexo / Hugo + 魔改主题 | 上手最快,一天能上线 | 想深度定制视觉时到处掣肘 | 只想尽快有站 |

**结论:走 A。** 这个项目的难点在视觉表达,不在数据处理,用轻量静态框架收益最大。

> 若你更想练 Java 后端(方案 C),**不要用 Thymeleaf 硬写动效**,改前后端分离:前端 Astro/React 做视觉 + Spring Boot 只提供 `/api` 接口。两份工作分别独立,后期也能平滑升级。

## 三、信息架构(Sitemap)

```
首页 /
├── 文章 /posts          → 卡片瀑布流,支持标签筛选

├── 归档 /archive        → 时间轴(按年月折叠)

├── 友链 /friends        → 友链卡片墙
├── 关于 /about          → 技能条(游戏化)、时间线、追番列表
├── 留言 /guestbook      → 留言板
└── 搜索 /search         → 前端全文检索
```

## 五、视觉设计规范

### 5.1 主题与配色(两套,可切换)

**主题 A ·「樱花初雪」(默认浅色)**

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 | `#FFF7F9` | 页面底色(带粉的暖白) |
| 卡片 | `#FFFFFF` | 卡片 / 面板 |
| 主色 · 樱 | `#FF8FB1` | 按钮、链接、强调 |
| 辅色 · 空 | `#A8D8EA` | 次级标签、分割线 |
| 点缀 · 星 | `#FFD166` | 高亮、下划线、徽章 |
| 正文 | `#4A3B47` | 正文(暖调深灰,**不用纯黑**) |
| 弱文 | `#9B8A94` | 时间、辅助说明 |

**主题 B ·「深夜电波」(深色)**

| 角色 | 色值 |
|---|---|
| 背景 | `#15151F` |
| 卡片 | `#1E1E2B` |
| 主色 | `#FF6BB5` |
| 辅色 | `#7BD9FF` |
| 点缀 | `#FFE066` |
| 正文 | `#E8E4F3` |
| 弱文 | `#8E8AA3` |

**配色原则**:粉 + 蓝双主色撞色;黄只做小面积高亮;全程禁止纯黑 `#000` 与纯白 `#FFF` 大面积铺底。

### 5.2 字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文标题 | 霞鹜文楷 LXGW WenKai / 站酷快乐体 | 前者文艺,后者呆萌,均免费商用 |
| 中文正文 | 思源黑体 / 阿里巴巴普惠体 | 免费商用 |
| 日文点缀 | Zen Maru Gothic | 圆体,二次元感强 |
| 数字 / 英文 | Baloo 2 / Nunito | 圆润,与中文标题气质统一 |
| 代码 | JetBrains Mono | 连字 |

> 字体本地化托管(`/public/fonts`),避免 Google Fonts 在国内加载失败。

### 5.3 视觉元素库

- 角色立绘(首页右侧约 40% 宽,PNG 透明底)
- 对话气泡(自我介绍、看板娘说话)
- 像素风 / 描边贴纸徽章(标签、状态)
- 网点纸 halftone 背景纹理(低透明度铺底)
- 手绘感分割线(波浪线 / 虚线 / 小星星串)
- 装饰图标:樱花、星星、爱心、音符、闪光
- 统一"贴纸风"卡片:**圆角 16px + 1.5px 有色描边 + 无阴影或极浅阴影**

### 5.4 动效清单

| 动效 | 实现方式 | 优先级 |
|---|---|---|
| 卡片悬停上浮 + 描边点亮 | CSS transition | P0 |
| 首页标题打字机效果 | 轻量 JS | P0 |
| 滚动淡入 (IntersectionObserver) | CSS + JS | P0 |
| 阅读进度"血条" | scroll 监听 + CSS | P1 |
| 鼠标樱花瓣拖尾粒子 | canvas | P1 |
| 卡片 3D 倾斜 | vanilla-tilt | P1 |
| 加载文案"少女祈祷中…" | 纯文案 + 骨架屏 | P1 |
| 页面切换过渡 | View Transitions API | P2 |
| 黑胶唱片式 BGM 播放器 | HTML5 Audio | P3 |
| Live2D 看板娘 | pixi-live2d-display | P3 |

### 5.5 交互约束

- 首屏 JS ≤ 100KB(gzip 后),超出即砍动效。
- 移动端自动关闭粒子、3D 倾斜、Live2D。
- 尊重 `prefers-reduced-motion`,用户系统开启减弱动效时全部降级为淡入。
- 深色模式跟随系统,可手动覆盖并记忆到 localStorage。

## 六、内容模型

文章文件 `src/content/posts/xxx.md`:

```yaml
---
title: Spring Boot 里那些坑
date: 2026-09-26
cover: /images/covers/spring.webp    # 缺省时用主题色渐变占位
excerpt: 记录我踩过的 12 个坑
category: 技术笔记
tags: [Java, SpringBoot, 踩坑]
mood: 元气            # 心情角标:元气 / 发呆 / 摸鱼 / 燃
top: false           # 置顶
draft: false         # 草稿不构建
---
```

其他数据(友链、画廊、追番列表)统一放 `src/data/*.json`,改内容不改组件。

## 七、开发路线图

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| **P0 骨架** | 定选型、初始化项目、写入设计 token(配色/字体/间距)、布局壳、双主题切换 | 空站点跑起来,配色字体全部生效 |
| **P1 核心** | 首页、文章列表、详情页(Markdown 渲染 + 代码高亮 + 目录)、归档 | 能完整发一篇带代码的文章并正常阅读 |
| **P2 二次元糖** | 立绘、气泡、粒子、悬停动效、血条 | 首页"有那味儿" |
| **P3 内容体系** | 标签、搜索、关于(技能条)、画廊、友链、留言 | 全部导航页面可用 |
| **P4 加分项** | 评论(giscus)、RSS、SEO / OG 图、访问统计、BGM、Live2D | 可被搜索引擎正常收录 |
| **P5 上线** | 部署(Vercel / GitHub Pages / 国内服务器)、域名、CDN、字体本地化 | 线上可访问,移动端体验正常 |

**顺序原则:先让文章能发,再堆特效。** 反过来做的话,大概率卡在"很酷但没内容"。

## 八、风险与取舍

| 风险 | 说明 | 对策 |
|---|---|---|
| 素材版权 | 立绘、图标、BGM 若非自制,商用有风险 | 用免费商用素材站 / 委托画师 / AI 生成并保留授权说明 |
| 性能拖累 | 粒子 + Live2D + 大图,手机端容易卡 | 移动端默认关闭重动效;图片统一 webp + 懒加载 |
| 字体体积 | 中文字体动辄 10MB+ | 用子集化(@fontsource / cn-font-split)按需裁字 |
| 内容断更 | 过度投入视觉,迟迟不发文 | P1 结束就必须发第一篇文章,再进 P2 |
| 主题漂移 | 两套主题后期容易走形 | 所有颜色只在 token 文件里定义,组件禁止写死色值 |
