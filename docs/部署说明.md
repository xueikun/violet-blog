# 部署说明(GitHub Pages)

**目标**:推到 `main` 分支 → 自动构建 → 发布到 `https://xueikun.github.io/violet-blog/`

不需要买域名,不用配 DNS,不用备案。推代码就上线。

---

## 一、创建代码仓库

| 项 | 值 |
| --- | --- |
| 仓库名 | `violet-blog` |
| 可见性 | **必须 Public** |

免费版 GitHub Pages 只支持公开仓库。

建仓库时**什么都别勾**——不要 README、不要 .gitignore。本地已经有这些文件了,在线上创建会造成冲突。

> 注意区分:评论用的 `violet-blog-comments` 是另一个仓库,用途不同,别混。

## 二、关联远程并推送

```bash
git remote add origin https://github.com/xueikun/violet-blog.git
git push -u origin main
```

推送时会要求登录。GitHub 早就不支持账号密码直推,密码位置要填 **Personal Access Token**(在 GitHub → Settings → Developer settings → Personal access tokens 生成,勾 `repo` 权限)。

第一次推送会触发 GitHub Actions 跑构建,**这一步大概率红叉失败**——因为 Pages 还没开启。属正常,继续下一步。

## 三、开启 GitHub Pages

仓库 → **Settings** → 左侧 **Pages** → **Source** 选 **GitHub Actions**

不要选 "Deploy from a branch",本项目用的是 Actions 工作流(已随代码提交在 `.github/workflows/deploy.yml`)。

开完之后,去 **Actions** 标签页,如果上一次失败了,点 **Re-run all jobs** 重跑一次。

## 四、访问

等 Actions 变绿,访问:

**https://xueikun.github.io/violet-blog/**

---

## ⚠️ 最重要的一条:子路径

站点部署在 `/violet-blog/` 这个**子路径**下,不是根路径。所以 `astro.config.mjs` 里配置了:

```js
site: 'https://xueikun.github.io',
base: '/violet-blog',
```

**这意味着:所有站内链接都必须带 `/violet-blog/` 前缀。**

项目里已经统一处理好了——所有链接都走 `src/utils/url.ts` 的 `url()` 函数。

### 以后加新页面时,千万不要手写这种路径

```astro
<!-- ❌ 错的:本地看着正常,部署上去 404 -->
<a href="/posts/">文章列表</a>
```

要这样写:

```astro
---
import { url } from "../utils/url";
---
<a href={url("posts/")}>文章列表</a>
```

**这是 base 部署最容易踩的坑**,而且症状很迷惑:本地 dev 能跑通,一上线所有链接全 404。

### 本地开发地址也变了

带 base 之后,本地预览地址是:

**http://localhost:4321/violet-blog/**

直接访问 `http://localhost:4321/` 会打不开,这是正常的,不是配置错了。

## 日常发布流程

写文章就三步:

```bash
# 1. 新建 md 文件:src/content/posts/你的文章.md

# 2. 提交
git add .
git commit -m "post: 文章标题"

# 3. 推送,自动部署
git push
```

推完等 1 分钟左右上线。进度去仓库 **Actions** 标签页看。

### 文章模板

```yaml
---
title: "文章标题"
date: 2026-09-27
excerpt: "一两句话摘要,显示在卡片上"
category: "技术笔记"
tags: ["标签1", "标签2"]
mood: "元气"
---
```

- `mood` 显示为卡片右上角的心情角标:元气 / 摸鱼 / 发呆 / 燃 / 平静
- `top: true` 置顶
- `draft: true` 标记草稿,不会被打包上线

## 如果以后想绑自己的域名

现在的链接全部走 `url()` 函数,所以换域名只需要改配置,组件一行都不用动:

1. `astro.config.mjs`:`site` 改成你的域名,`base` 改成 `'/'`
2. 新建 `public/CNAME`,内容写域名(一行)
3. 域名服务商处加 A 记录指向 `185.199.108~111.153`
4. 仓库 Settings → Pages → Custom domain 填域名,勾上 Enforce HTTPS

改完 `url()` 会自动适配(base 变成 `/`),不用去动任何组件。
